## 🛠️ Tecnologias e Conceitos Aplicados

Neste projeto, apliquei conceitos fundamentais de desenvolvimento Front-End:

- **HTML5 Semântico:** Uso de tags como `<main>`, `<ul>` e `<meta>` para SEO e acessibilidade.
- **CSS3 Moderno:** Flexbox para centralização e estilização de botões.
- **Design Responsivo:** Uso de `@media queries` para garantir que o cartão fique perfeito em celulares e desktops.
- **Open Graph (Social):** Configuração de meta tags para que o compartilhamento no WhatsApp e LinkedIn exiba imagem e descrição profissionais.
- **Versionamento:** Uso de Git e GitHub para controle de alterações e deploy.

## 🧠 Aprendizados e Desafios (DebuggeLog)

Durante o desenvolvimento, resolvi desafios importantes como:
1. **Alinhamento de Listas:** Ajuste de padding padrão do navegador para centralização perfeita.
2. **Cache de Redes Sociais:** Uso de meta tags `og:image` e `og:title` para previews profissionais.
3. **Fluxo de Branch:** Transição de branch `master` para `main` para deploy no GitHub Pages.
